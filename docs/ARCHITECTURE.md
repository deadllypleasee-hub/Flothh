# Архитектура

## Мир и физика

Корень `GameManager` создаёт единственный 3D-мир. X/Z — горизонтальная плоскость, Y — высота; одна единица равна одному метру, нос модели смотрит вдоль −Z. Карта преобразует те же координаты, не содержит отдельной симуляции. При переключении судна меняется флаг `player_controlled`, ссылка камеры и HUD; существующие корабли и снаряды сохраняются.

`ShipController` использует CharacterBody3D: инерционный разгон и руль, ограниченный задний ход, сопротивление, боковой снос ветром и упрощённые столкновения. Масса — характеристика каталога; полной силовой модели массы и гидродинамики нет. `BuoyancySystem` считывает высоту волн в четырёх точках корпуса. `OceanSystem.height_at()` и шейдер используют одинаковые выражения и общий clock. Корпус получает вертикальное перемещение, крен и дифферент, визуальная модель качается независимо от простого коллайдера.

`SubmarineController` переопределяет вертикальную динамику: заданная глубина управляет балластом и горизонтальными рулями. Есть инерция вертикальной скорости, расход воздуха, аккумуляторы дизельной лодки, шумность и аварийное всплытие. Глубина ограничена 150 м, рабочая уставка — 140 м. Подводное дно — плоскость на −180 м и процедурные камни. Контакты с дном не моделируются полноценно.

| GameManager | Жизненный цикл режимов, флот, обнаружение, передача управления, результаты |
| VesselCatalog | Девять наборов вымышленных характеристик и начальная расстановка |
| ShipController / SubmarineController | Горизонтальная и отдельная подводная динамика |
| ShipModel | Оригинальные процедурные корпуса, надстройки, башня, винт, упрощённые детали |

| TerrainSystem / WeatherSystem | Острова, порт, буи, маяк, свет, дождь и цикл суток |
| CameraManager | Внешняя, мостик/рубка, перископ, свободная, верхняя, снаряд, кино |
| TacticalMap | Реальные координаты, скрытые контакты, масштаб, выбор и маршрут |
| ScenarioEditor | Расстановка, типы/команды, параметры боя, валидация |
| CombatSystem | Проверки выстрела, дальность, боезапас, перезарядка, пул и урон |
| ProjectileController / MissileController / TorpedoController | Баллистика или ограниченное наведение, непрерывное обнаружение попаданий |
| DamageSystem / CrewSystem | Корпус, три условных отсека, механизмы, пожар, вода, ремонт и эффективность |
| AIController | Патруль, маршрут, атака, отступление и простое избегание препятствий |
| MissionManager / EconomyManager | Десять целей заданий, награды, открытия, улучшения, обслуживание |
| SaveManager | JSON-конверт версии 1, временная запись, атомарная замена и .bak |
| SpectatorController | Передача всего флота ИИ, управление временем, выбор камеры события |
| MobileControls / VirtualWheel | Русский адаптивный интерфейс и мультитач |
| EffectsManager | Ограниченные GPU-эффекты, вспышки, следы, синтезированные звуки |

## Бой и обнаружение

Обнаружение пересчитывается раз в 0.5 с отдельно для каждой команды. Дальность зависит от сенсоров, повреждения радара и глубины контакта. Это игровая эвристика без распространения звука, рельефного экранирования и реалистичной радиолокации. Управляемое оружие допускает запуск только по обнаруженной вражеской цели. Уже запущенный боеприпас продолжает упрощённое наведение после потери контакта.

Пул ограничен 64 снарядами, неактивные объекты используются повторно. Движущийся отрезок снаряда проверяется против эллипсоидов корпусов в локальных координатах судов и лучом против статического рельефа. Это предотвращает пролёт быстрого снаряда насквозь между физическими тактами. Случайное попадание в союзника возможно; специальной системы предотвращения дружественного огня нет.

Физика работает на 30 тактах/с. ×4 увеличивает шаг симуляции; попадания защищены от туннелирования отрезком. Короткий автоматический прогон проверяет конечность координат, но не доказывает стабильность всех возможных пользовательских расстановок.

## Сохранения

`user://progress.json` хранит валюту, репутацию, открытия, улучшения, пройденные миссии и настройки. `user://scenario.json` — один пользовательский слот с начальной расстановкой, картой, погодой, волнами, ветром, командами, курсами, скоростями, сложностью и условиями боя. Рядом хранится предыдущая `.bak` копия. Неизвестная версия конверта отклоняется; повреждённый основной файл восстанавливается из резервного. Миграции на будущие версии пока нет.

Настройки редактора проверяются до загрузки/старта. Незнакомые классы, отсутствующие/нечисловые/бесконечные координаты, слишком большой курс, выход за границы, неверные типы погоды/ночи/сложности/индекса и превышение 24 судов отклоняются. До изменения расстановки проверяются пересечения ориентированных прямоугольников корпусов по четырём осям SAT; береговые зоны проверяются по радиусам островов. Неудачные перемещение, поворот и дублирование сохраняют прежние объекты. Причалы и подробные береговые меши в этой проверке не участвуют. Сценарий не содержит состояние летящих снарядов или текущие повреждения: сохранение/продолжение боя посреди операции ещё не реализовано.

`TacticalMap` выдаёт команду только при отпускании короткого касания. Перетаскивание, отменённый ввод и мультитач не создают команды. После отпускания одного из пальцев масштабирования оставшийся палец игнорируется до завершения жеста. При скрытии карты ввод сбрасывается. Очередь автопилота ограничена 32 точками, нечисловые и внекартовые точки отклоняются без потери маршрута.
