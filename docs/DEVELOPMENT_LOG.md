# Контрольные точки разработки

Исходный рабочий каталог не содержал Godot-проекта или доступного Git-репозитория. Новый проект создан в отдельном каталоге `fortis-deep-waters`; существующие пользовательские файлы не удалялись.

1. `8caae3a` — начальная играбельная 3D-основа, физика корабля/подлодки, бой, карта, редактор, режимы и 64 интеграционные проверки. Перед фиксацией выполнен прогон; исправлены загрузка числовой команды после JSON и выбор активного снаряда в тесте переключения.
2. `3a10c70` — доработка эффектов, звука, жизненного цикла судов, меню лицензий, маркеров и сквозного боевого теста. Перед фиксацией: 64 основных + 22 сквозные проверки, визуальный запуск через OpenGL, повторный экспорт APK и проверка подписи. Исправлены предупреждения тестового аудиодрайвера и обращение к удалённому судну.
3. Следующая фиксация содержит Android presets, debug/release workflows, утилиты сборки, документацию и отчёты. YAML разобраны локально; удалённый Actions run и релизная публикация остаются следующими действиями после назначения GitHub remote и предоставления ключа владельцем.

В этом сеансе выполнен широкий прототип нескольких этапов мастер-промпта. Это не означает завершения визуальной полировки и релизного этапа: аппаратная Android-проверка, полноценное прохождение миссий и релизная подпись ещё впереди.

## Продолжение: 0.1.1

Исправлены случайные команды карты при начале перетаскивания/масштабирования, двойные команды эмулированной мыши, оставшийся палец после pinch и незавершённые жесты при закрытии карты. Добавлена сенсорная очередь до 32 точек. Начальный курс редактора приведён к компасным градусам и направлению носа модели.

Редактор проверяет пересечения ориентированных корпусов и островов; неудачные изменения сохраняют прежние объекты. Исправлены недостающие проверки полей сценария и сохранение индекса управляемого судна после удаления предшествующего. Параметры редактируются в копии, проверяются при применении, отмена не меняет данные. Новые 47 регрессионных проверок и прежние 86 проверок выполнены успешно; оба workflow дополнены новым набором. Версия APK — 0.1.1, versionCode — 2, формат сохранений остаётся версией 1.
