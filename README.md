# FORTIS: DEEP WATERS

**FORTIS GAMES · играбельный 3D-прототип 0.1.1 · Godot 4.6.3 · Android ARM64**

Настоящий офлайн-проект Godot на типизированном GDScript: океан, управление кораблями и подлодками, морской бой, редактор и наблюдатель работают в одном 3D-мире. Процедурные модели, материалы и синтезированные звуки создаются исходным кодом. Все суда и характеристики оружия вымышлены.

Это тестовая сборка, а не законченный коммерческий симулятор. Реализованные системы и ограничения подробно перечислены в [docs/STATUS.md](docs/STATUS.md).

## Быстрый старт

1. Откройте `project.godot` в **Godot 4.6.3 Standard** и нажмите F6/F5 для запуска главной сцены/проекта. .NET не требуется.
2. Выберите **«Быстрый бой»** либо **«Редактор сражений»**.
3. В редакторе кнопка **«Пример 3+2 / 4+2»** создаёт три союзных эсминца, две союзные подлодки, четыре вражеских корабля и две вражеские подлодки. Выберите **«Открытый океан»**, шторм и ночь.
4. Нажмите **«НАЧАТЬ БОЙ»**, затем **«Выбрать цель» → «Ракета» → «ОГОНЬ» → «ПОЛЁТ»**.
5. Через карту выберите союзную подлодку и **«Взять управление»**. **«+10 м»** увеличивает заданную глубину. Выберите торпеду и обнаруженную цель.
6. **«Наблюдатель»** передаёт весь флот ИИ. Кнопка **«Камера»** переключает ракурсы, штурвал перемещает свободную камеру.

После боя можно сохранить начальный сценарий и повторить его. Сохранение сценария доступно и до боя. Это сохранение расстановки, а не снимок текущего сражения.

## Управление

| Действие | Android | Клавиатура / мышь |
|---|---|---|
| Ход, включая задний | Вертикальный телеграф | W / S |
| Руль | Виртуальный штурвал | A / D |
| Остановить двигатель | «СТОП» | Установить телеграф в ноль |
| Камера | Жест по свободной области, два пальца для масштаба | Правая кнопка + движение, колесо |
| Выбрать цель / огонь | Кнопки справа | T / Пробел |
| Орудие / ракета / торпеда | Выпадающий список | 1 / 2 / 3 |
| Карта / смена судна / камера | Экранные кнопки | M / Tab / C |
| Глубже / мельче | +10 м / −10 м | [ / ] |
| Пауза | Ⅱ | Esc |
| Свободная камера | Штурвал + жест направления | W/A/S/D, Q/E по высоте |

Короткое касание пустой области полной карты назначает точку автопилота. Включите **«Добавлять точки»**, чтобы набрать маршрут пальцем, до 32 точек. Shift + щелчок тоже добавляет следующую точку. Перетаскивание и масштабирование карты не назначают маршрут и не создают суда в редакторе. Ручной ход отменяет автопилот; перед новым манёвром отключите его на карте. Неизвестные противники скрыты; в редакторе и режиме наблюдателя видны все суда.

## Android APK

`build/fortis-debug.apk` — локальная тестовая сборка; не хранится в Git. Требуются Android 7.0 / API 24+, ARM64 и OpenGL ES 3.0. Подробности установки и сборки: [docs/ANDROID.md](docs/ANDROID.md).

```bash
adb install -r build/fortis-debug.apk
```

Либо перенесите APK на телефон, откройте файл и разрешите установку для выбранного файлового менеджера. Debug-ключ не предназначен для публикации. Выпуск обновлений с другой подписью потребует удаления установленной debug-версии, что удалит её локальные сохранения.

## Проверки

```bash
godot --headless --path . --editor --quit
godot --headless --path . --fixed-fps 30 --script res://tests/run_tests.gd
godot --headless --path . --fixed-fps 30 --script res://tests/scenario_test.gd
godot --headless --path . --fixed-fps 30 --script res://tests/navigation_test.gd
```

Всего 133 проверки: 64 проверки основных систем, 22 проверки последовательного боя и короткий прогон ИИ на ×4, 47 проверок жестов, маршрутов, курса, размещения и применения настроек. Результаты и границы проверки: [docs/TEST_REPORT.md](docs/TEST_REPORT.md). Для тестов используйте отдельный пользовательский каталог: они пишут тестовые сохранения в `user://`.

## Автоматическая сборка

`.github/workflows/android.yml` импортирует проект, проверяет логи и игровые системы, собирает и проверяет подписанный debug APK, загружает APK и журналы в Actions Artifacts. `.github/workflows/release.yml` запускается вручную и использует GitHub Secrets для подписи release APK. Публикация в магазин автоматически не выполняется.

Репозиторий проекта: [deadllypleasee-hub/Flothh](https://github.com/deadllypleasee-hub/Flothh). Тестовые APK доступны в [GitHub Actions](https://github.com/deadllypleasee-hub/Flothh/actions/workflows/android.yml): откройте успешный запуск и скачайте `fortis-android-debug-N` в разделе Artifacts. Для скачивания артефактов войдите в GitHub. Статус конкретной сборки смотрите на странице запуска; локальные проверки сами по себе не подтверждают выполнение CI. Подготовка публикации в магазин: [docs/RUSTORE.md](docs/RUSTORE.md).
